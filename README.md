Exactly one emoji, 1 character, for my dream vacation: 🏝 (desert island). No flight, no hotel, no itinerary, no people — just sand, one palm tree and the sea in every direction. The program reads the emoji from `entry.txt`, checks it rule by rule against the bounty gate (UTF-8, 1–8 characters, exactly one character, that character an emoji, no invisible joiner), and publishes it byte for byte to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
